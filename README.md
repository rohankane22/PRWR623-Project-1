# Installing spaceKLIP
spaceKLIP is a Python package developed for processing high-contrast imaging data from the James Webb Space Telescope. 

It currently cannot be installed with pip, and requires a more involved hand to configure the package and reference files after basic installation. These additional steps are not collated in one location, and can be daunting without prior experience with the package. Follow along with these steps to fully install spaceKLIP so that you are ready to begin reducing and analyzing JWST data.

This tutorial assumes a MacOS or Linux-based operating system, along with a bash shell and either Anaconda or Miniconda distribution platforms. This tutorial, published in September 2026, will install version 2.2.0 of spaceKLIP, which requires a Python version <= 3.11. The requirements.txt file will ensure versions of dependent packages do not conflict with one another.
