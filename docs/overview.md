spaceKLIP is a calibration pipeline and data analysis tool for high-contrast data taken by the James Webb Space Telescope (JWST). The tutorial will take you through three stages to complete your installation of spaceKLIP:

1. Configure a directory and an environment on your local machine to host spaceKLIP.

2. git clone the repository to your machine and run the basic pip installation steps.

3. Download telescope reference files from Space Telescope Science Institute (STScI) servers and add their path to your bash profile.

This link will take you to the tutorial with detailed step-by-step instructions for the installation: [https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/procedure.md](https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/procedure.md)

The most common problem users experience in this process occurs in Step 2, when attempting to install the cloned repository with pip. In some occurrences, pip will fail to build a wheel for a dependent package. This link will provide more detail on how to use conda-forge to complete the installation: [https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/troubleshooting.md](https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/troubleshooting.md)

Should the user be interested in the minutiae of any of the packages or databases spaceKLIP is built on, links to the documentation of those sources can be found here: [https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/sources.md](https://github.com/rohankane22/PRWR623-Project-1/blob/main/docs/sources.md)
